4라운드 레이아웃 수정은 최초 HTML을 보관하고 동일 Claude 세션에 요청했다.
수정 전후 HTML에서 스크립트·스타일을 제외한 **전체 본문 텍스트가 동일함**을
브라우저 DOM으로 비교했다. 리뷰 내용·인용·귀속·수치를 수작업으로 변경하지 않았다.

9월 29일에는 `You've hit your session limit`로 중단됐고 초기화 안내는
`1:50am (Europe/Berlin)`이었다. 9월 30일 같은 Claude 세션에서 5라운드를 재개했다.
추출·설계는 완료됐으나 HTML 빌드가 600초를 넘기자 CLI가 백그라운드 작업을
종료했다. 이때 프로세스 종료 코드는 0이었지만 HTML·감사는 미완료였다.
CLI 오류 안내에 따라 실행 프로세스에 `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS=0`을
설정하고 빌드부터 다시 요청했다. 추출·설계는 반복하지 않았다.

재개한 빌더는 HTML을 저장했으나 감사 호출 전에 다시 사용 한도에 도달했다.
초기화 안내는 같은 날 `3:10pm (Europe/Berlin)`이었다. 사용자가 계정을 변경한 뒤
같은 모델·세션에서 최종 감사 담당만 실행했다. 계정 식별 정보는 공개하지 않는다.

HTML의 호스트 보완은 Codex가 수행했다. 빌더가 생략한 비표시 필드를 포함해
`const DATA`를 원본 JSON 전체와 일치시켰다. 기존 내장 값이 원본의 부분 집합임을
먼저 확인했고 값은 바꾸지 않았다. `.mx-scroll`에 `position: relative`를 추가해
숨겨진 접근성 텍스트가 좁은 화면에서 문서 밖으로 배치되는 문제를 수정했다.
차트는 최소 720px 폭을 영역 내부에서 스크롤해 글자가 작아지지 않게 했다.
이 최초 레이아웃·누락 필드 보완에서는 전후 렌더링된 **전체 보고서 본문 텍스트가
동일함**을 두 브라우저에서 확인했다.

첫 감사는 필수 수정 2건을 발견했다. 상위 이슈 3위에서 관련 지적인
`systems-designer/F5`를 원본 지적과 구분하지 않았고, 충돌 항목에서 지지 근거로만
인용한 동료도 충돌 상대에 포함했다. Codex 호스트가 파생 JSON의 `related_findings`를
분리하고, 충돌 집계를 원문 항목의 `peer_reviewers`로 바꿨다. 근거 인용은 상세에
별도로 남겼다. 원본 리뷰·종합과 30개 지적 본문·심각도는 그대로다.

같은 수정에서 심각도 단서의 병기 원문, 쟁점 요약 라벨의 출처, 차트 숫자 표시를
맞췄다. 중복된 “전체” 버튼의 키보드 포커스는 고유 키로 유지하고, Esc 한 번으로
툴팁과 쟁점 패널을 닫도록 보완했다. 이 감사 수정은 잘못된 귀속·표시·집계를
바꾸므로 위의 최초 본문 보존 비교와 구분한다. 수정본으로 브라우저 검사를 다시
실행한 뒤 Claude 감사 담당만 재실행했다.

재감사에서는 `player-psychologist`의 C1에 QA가 논쟁 상대로 남아 있는 오류를
발견했다. 원문에서 QA/F3은 지지 근거이므로 `peer_reviewers`에서 QA만 제거하고
근거 참조는 보존했다. 이에 따라 심리→QA 칸은 충돌 1·연결 2가 된다.
참조 지적·추출자가 연결한 쟁점·자기평가 요약의 라벨도 구분했다. 초기화 뒤
필터 막대에 포커스를 유지하고, V2 밖에서 Esc를 누르면 포커스가 이동하지
않도록 보완했다. 원본 GDD·리뷰·종합과 지적 30개의 내용·등급은 바꾸지 않았다.

[첫 감사](./reviews/viz-audit-initial.md)와 [재감사](./reviews/viz-audit-recheck.md)는
각 수정 전의 상태를 기록한 문서다. [최종 확인](./reviews/viz-audit.md)은 남은 A1과
명시한 수정 사항만 확인했으며, 전체 감사를 처음부터 다시 수행하지 않았다.
최종 판정은 **“바로 보여 줄 수 있다”**, 남은 필수 수정은 **0건**이다.
권장 사항은 남아 있다. 예를 들어 V5 자기평가 라벨의 일관성과 V1 수정 요약
라벨, 작은 글자의 프로젝터 가독성은 후속 개선 대상으로 보관했다.

감사자는 브라우저를 실행하지 않았고, 읽기 한도를 넘는 HTML의 인라인 DATA와
파일 해시를 직접 확인하지 못했다. 이 두 항목은 호스트가 실제 브라우저에서
JSON 전체 동일성을 비교하고 HTML의 SHA-256을 계산해 검증했다. 최종 확인과
브라우저 검증이 참조한 HTML 해시는
`c788fcd9ce5d1bbc059515859ee81b02ce9fd4e05897a7695acb316fc193add8`이다.
소스 검토와 브라우저 검증을 같은 검사로 취급하지 않는다.

## 수치와 출처 검증

- 1라운드 지적: **30개**, 각 리뷰어 5개. `(reviewer, finding_id)` 조합이 모두 고유함.
- 1라운드 심각도: **BLOCKING 2 / MAJOR 21 / MINOR 7**.
- 2라운드 수정 반영 심각도: **BLOCKING 3 / MAJOR 19 / MINOR 8**.
  검토 보드 마스트헤드는 이 기준을 명시하고 1라운드 수치도 함께 표시함.
- 2라운드 뒤 여섯 파일의 최초 본문이 모두 동일한 접두부로 유지됨.
- 각 리뷰어가 동료 **5명**의 구체적인 지적 ID를 참조함.
- 리뷰 전체에서 지적 참조 222개, 종합 보고서에서 58개를 원본 지적 목록과
  대조했으며 존재하지 않는 ID는 없음. 이는 참조 출현 횟수이며 지적 수가 아님.
- 명시적인 근거 블록에서 추출한 인용 92개 중 91개는 공백 정규화와 말줄임표
  구간 분리 후 GDD 원문에서 확인됨. 1개(`player-psychologist/F4`의
  “계단을 열려면 모든 적을 처치”)는 7절의 “해당 층의 적을 모두 처치해야 열린다”를
  요약한 표현임. 원시 리뷰는 그대로 보관함. 기술 실현성 리드의 문제·누락 형식은
  이 근거 블록 추출 검사의 대상이 아니므로 모든 인용의 문자 단위 일치를 주장하지 않음.
- 리뷰 입력과 공개 GDD의 파일 해시가 실행 뒤에도 동일함.
- 5라운드 [추출 데이터](./reviews/viz-data.json)와 [설계 명세](./reviews/viz-spec.md)를
  저장함. [데이터 대조 결과](./reviews/data-validation.json)는 원본 지적 ID·귀속,
  라운드별 심각도·집계, 충돌 30개·연결 26개의 항목 ID·참조, 상위 이슈의 순위·등급·결과,
  종합 요지·쟁점 논지·판정과 입력 보존을 확인함.
- [파이프라인 대조 결과](./reviews/pipeline-validation.json)는 원시 실행 이벤트에서
  리뷰어 호출, 추출·설계의 독립 입력과 병렬 실행, 두 작업 완료 뒤 빌더 호출,
  세 차례 감사의 입력·파일 저장·정상 종료를 확인함. 계정 정보와 원시 로그는 포함하지 않음.

이 검사는 산출물의 수치·참조와 원본 보존을 확인한다. 각 리뷰어의 계산 전제,
해석, 권고에 대한 설계자의 수용 여부는 확정하지 않았다.

## 실제 브라우저 검증

검증 도구는 Playwright `1.63.0`이다. 보고서를 `file://`로 열고 네트워크 연결을
차단한 상태에서 검사했다. [검토 보드 검증](./reviews/browser-validation.json)과
[시각화 검증](./reviews/viz-browser-validation.json)에 실측 환경과 결과를 보관했다.
시각화 검증에는 검사한 HTML의 SHA-256도 포함했다.

| 환경 | 화면 | 결과 |
| --- | --- | --- |
| Chromium / Microsoft Edge `154.0.4258.37` | 1440×1000, 390×844 | 통과 |
| Firefox `155.0` / Playwright 배포 빌드 | 1440×1000, 390×844 | 통과 |
| Safari | 미검증 | 실행 환경 없음 |

확인한 항목:

- 한국어 문서 메타데이터, UTF-8, 한글 렌더링과 화면 배치.
- 외부 HTTP 요청 **0건**, JavaScript·콘솔 오류 **0건**.
- 리뷰어 탭 6개의 클릭과 좌우 화살표 키 전환.
- 탭마다 지적 5개와 안정적인 `F1`~`F5` 표시, 활성 패널 하나만 표시.
- 두 화면 크기에서 문서 전체의 가로 넘침 없음.
- 레이아웃 수정 뒤 전체 보고서 본문 텍스트 보존.

캡처는 모션 감소 설정에서 실제 렌더링한 화면이며
[검토 보드 이미지](./review-board-preview.png)에 보관했다.

5라운드 시각화에서 추가로 확인한 항목:

- 내장 JSON 전체의 구조·값이 추출 JSON과 동일함.
- 30개 지적의 리뷰어·ID·제목·최종 심각도·문제 본문·표시된 근거가 JSON과 일치함.
- 리뷰어 단일·복수 선택, 심각도와 등급 기준 전환, 변경 지적·동료 언급 필터,
  심각도 정렬, 결과 0건 안내와 초기화.
- 키보드로 지적·상위 이슈 5개·쟁점 6개 펼치기, Esc로 쟁점 닫기, 포커스 툴팁.
- 교차 검토 30칸의 수치를 충돌의 주 논쟁 상대와 연결의 원본 참조 ID 기준으로
  대조, 지지 근거 인용 구분·상세 보기·반대 방향·모드 전환.
- SVG 차트의 라운드 전환과 키보드 필터 연결, 차트에서 설정된 필터 표시.
- 필터에 가려진 지적도 복합 ID 링크를 누르면 정확한 행으로 이동하고 펼쳐짐.
- 원본·관련 지적의 화면 귀속, 필터·초기화 버튼의 포커스 유지,
  툴팁이 열린 쟁점도 Esc 한 번으로 닫힘.
- 다크·라이트 선호 반영, 모션 감소 설정, 두 화면의 가로 넘침 없음.

[시각화 캡처](./review-viz-preview.png)는 같은 파일을 Edge에서 실제 렌더링했다.
