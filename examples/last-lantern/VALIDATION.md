# 게임 실행 검증

검증일: 2026-09-29. GDD 리뷰 라운드는 실행하지 않았습니다.

## 환경

- Windows, Godot `4.7.2.stable.official.ed1daf0bf`
- Compatibility 렌더러, OpenGL 3.3, NVIDIA GeForce RTX 5090 Laptop GPU
- 한글 표시: 시스템 글꼴 맑은 고딕

## 확인한 내용

- Godot 편집기의 프로젝트 가져오기 완료. GDScript 구문 오류 없음.
- 별도 검증 스크립트 없이 프로젝트의 기본 시작 장면 실행 확인.
- `.godot` 캐시를 제외한 프로젝트 ZIP을 새 폴더에 풀고, Godot의 첫 가져오기와
  기본 시작 장면 실행을 다시 확인. 원래 프로젝트 경로에 대한 의존 없음.
- seed 0~29의 3개 층, 총 90개 맵에서 전체 바닥 연결, 계단·적·아이템의
  도달 가능성, 안전한 시작점, 겹치지 않는 배치와 닫힌 외벽 확인.
- 같은 seed의 초기 맵·적·아이템 재현 확인.
- 실제 Godot 키 입력 이벤트로 Space의 턴 진행, 반복 키 입력 무시,
  R의 재시작 확인창과 취소 시 진행 유지 확인.
- HP가 가득 찼거나 물약이 없을 때 물약과 턴을 소비하지 않는 동작 확인.
- 실제 게임 규칙에 이동·공격·회복 입력을 순차 전달해 아래 세 판을 완료.
  HP·공격력·경험치·적·층 진행을 조작하지 않고 승리함.
- 적에게 실제로 공격받아 HP 0으로 패배하고, 결과 화면의 버튼으로 시작
  능력치·레벨·처치 수·턴이 초기화되는 새 게임 확인.
- GPU 렌더링으로 시작·탐험·재시작 확인·승리·패배 화면을 확인.
  한글 표시와 주요 UI의 배치를 확인했으며 `preview.png`는 실제 탐험 화면임.
