# 리뷰 반영판 검증

실행일: 2026-09-30. 생성 모델 `gpt-6.1-sol` / effort `high`.
Windows, Godot `4.7.2.stable.official.ed1daf0bf`, Compatibility 렌더러.

## 기존 산출물 보존

두 번째 게임 착수 전 [원본 해시 목록](./original-integrity.json)을 만들었다.
기존 리뷰·종합·시각화 데이터·감사·검증 파일과 원본 GDD·게임 소스의 **19개 파일**을
최종 작업 트리와 SHA-256으로 대조했다. 기존 리뷰에는 새 반영 내용을 덧붙이거나
지적·등급·문구를 수정하지 않았다. 원본 Godot 코드와 GDD도 변경하지 않았다.

웹 내보내기는 원본의 빌드 사본에 동봉 한글 글꼴과 상태 전달을 추가한다.
규칙·수치·승리 조건은 원본 코드 그대로다. 변경 범위는
[내보내기 스크립트](../../tools/export-demos.ps1)에 명시했다.

## 엔진 자체 검증

별도 실행 하네스 없이 기본 장면에서 시작한다. 게임 내부의
`--check-seeds=100` 모드로 실제 규칙 메서드를 실행했다.
[전체 결과](./native-validation.json)에 **1,648개 검사**, **300개 층**,
강제 폴백 **3개 층**, 오류 **0건**을 기록했다.

확인한 항목:

- 모든 바닥·적·아이템·목표의 연결, 중복 없는 배치, 적과 시작점의 경로 거리 ≥8.
- 층별 적·보급 수, 3층 계단 없음과 왕좌 위치, 유한 재시도와 강제 고정 폴백.
- 같은 seed·입력의 상태 재현과 이전 RNG 소비와 독립적인 다음 층 생성.
- 벽·HP 가득 참의 무비용 안내, 연속 안내 중복 억제, 확인창 중 행동 차단.
- H/O의 배타적 물약 배분, 가득 찬 물약·회복 구슬의 바닥 보관 방지.
- 수문장 처치 뒤 남은 적 행동, 열린 계단 위 Enter, 층 전환 턴의 새 적 대기.
- 마왕의 예고·한 칸 회피·피해 8·왕좌 고정.
- 마왕 처치가 연료 소진·남은 적 행동보다 우선, 마왕 경험치·레벨업 없음.
- HP 사망·연료 사망·같은 seed와 새 seed의 진행 초기화.

위의 경계 검사는 제어된 상태를 만드는 검사다. 아래 자연 승리 기록과 구분한다.

## 자동 정책 비교

능력치·HP·연료·적을 조작하지 않고 이동·공격·회복·연료·층 이동 메서드만
호출했다. 각 정책은 seed 0~19를 사용했다.

| 정책 | 자연 승리 | 승리 턴 범위 |
| --- | ---: | ---: |
| 수문장 우선, 필요한 전투·보급 | 11 / 20 | 78~118 |
| 보급·선택 전투 포함 | 11 / 20 | 106~153 |

두 경로 모두 승리했고, 추가 전투는 더 많은 턴·연료와 경험치를 소모/획득했다.
실패 사례도 그대로 보관했다. 사망이나 연료 부족을 숨기기 위해 결과를 선별하지
않았다. **55%는 이 자동 정책의 승률이며 사람의 첫 판 승률이 아니다.**

## 실제 렌더링과 웹 게임

네이티브 NVIDIA OpenGL 렌더링으로 [개선본 화면](./preview.png)을 캡처했다.
동봉 Noto Sans KR을 weight 500으로 표시해 시스템 한글 글꼴에 의존하지 않는다.

공식 Godot 4.7.2 단일 스레드 템플릿으로 두 게임을 내보내고, 로컬 정적 HTTP
서버에서 브라우저를 실행했다. [브라우저 결과](./web-validation.json)에는 다음을 기록했다.

- Edge `154.0.4258.37`와 Firefox `155.0` 모두 실제 두 게임 시작·seed 42·키 입력 통과.
- 원본 Space 뒤 턴 1·연료 규칙 없음, 개선본 Space 뒤 턴 1·연료 89.
- 개선본 O 입력 뒤 물약 0·연료 108·HP 28로 실제 자원 배분 확인.
- 반영표 30개와 ID 검색, 1440px·390px 페이지 가로 넘침 없음.
- JavaScript·브라우저 콘솔 오류 0건. 네트워크는 로컬 정적 파일만 사용.

[Edge 자연 플레이 기록](./web-playthroughs.json)은 seed 3에서 키 입력만 사용했다.

| 게임 | 결과 | 행동 | 처치 | 최종 HP | 최종 연료 |
| --- | --- | ---: | ---: | ---: | ---: |
| 원본 | 승리 | 105턴 | 13 | 36 | 규칙 없음 |
| 리뷰 반영판 | 승리 | 78턴 | 4 | 20 | 52 |

두 게임의 생성·정책·규칙이 달라 이 기록을 통제된 A/B 실험이나 개선 효과의
인과 추정으로 해석하지 않는다. 수문장 이후의 선택 전투·마왕 즉시 승리가
실제 게임에서 작동한다는 사례다. 확인창 중 이동/H/O 차단·Escape 취소와
결과 화면의 새 seed 재시작도 두 웹 게임에서 확인했다.

## 미확인 범위

- 외부 초보자의 첫 판 승률 40~80%, 완주 시간 중앙값 5~10분, 규칙 이해도·재미.
- Safari, 실제 모바일·터치, 다른 OS·Godot 버전.
- 공개 GitHub Pages URL 접속 및 캐시·대역폭 조건.
- 이 개정 GDD에 대한 새로운 독립 리뷰. 기존 리뷰의 해결 판정은 갱신하지 않았다.

자동·기술 검증 통과와 사람의 설계 목표 달성을 구분한다. 외부 관찰은 실행
계획의 사용자 시험 단계에서 측정할 항목으로 남긴다.
